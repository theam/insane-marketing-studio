# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be welcoming, be kind, assume good faith, and keep criticism about the work. Harassment, insults and
discrimination of any kind aren't tolerated in issues, pull requests or anywhere else the project lives.

To report behaviour that breaks it, use GitHub's **Report content** on the comment or issue, or open a private security
advisory (see [SECURITY.md](SECURITY.md)) if it shouldn't be public. The maintainers at The Agile Monkeys will review
every report, keep it confidential, and act as the Covenant's enforcement guidelines describe.
